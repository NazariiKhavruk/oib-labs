# Конспект до лабораторної роботи 1: випадкові числа

Криптографія спирається на випадкові числа: з них створюють ключі, вектори ініціалізації та солі. Якщо їх можна передбачити, надійність алгоритму не має значення.

Псевдовипадкові числа в .NET дає клас Random. Генератор детермінований: за однакового початкового значення (seed) видає однакову послідовність. Це зручно для моделювання, але неприйнятно для безпеки, бо знаючи або вгадавши seed (наприклад, за часом запуску), можна відновити всі числа.

Криптографічно стійкі випадкові числа в .NET дає клас RandomNumberGenerator (метод GetBytes). Він використовує джерела ентропії операційної системи, тому послідовність не повторюється і не відновлюється за попередніми значеннями.

Висновок: Random придатний лише для некритичних задач. Ключі, солі та інші секрети потрібно генерувати через RandomNumberGenerator.
